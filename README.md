
# Arabic Text Image Generator

This is a Streamlit app that generates a beautiful image containing fully vowelled Arabic text centered on a light background.

## How to Use

1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `streamlit run app.py`
3. Download the image directly from the interface.

## Notes

- Ensure the font file `NotoNaskhArabic-Regular.ttf` is included.
